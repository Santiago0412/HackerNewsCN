# Hacker News 中文助手

一个无需账号的 Chrome / Chromium 浏览器扩展。它直接增强 `news.ycombinator.com`：用用户自己的大模型 API 翻译标题和评论，并可按兴趣突出或过滤新闻。

界面使用统一的 HN 橙与暖灰视觉系统；Logo 延续 Hacker News 经典的白色 `Y` 标识。

## 功能

- 自动或手动批量翻译 Hacker News 标题，可随时切换中英文
- 点击扩展图标即可在浏览器侧边栏查看热门、最新、最佳、问答和作品，无需先打开 HN 网页；切换标签页时阅读器保持打开
- 可在内置阅读器直接查看并翻译新闻讨论
- 点击外链新闻时由侧边栏抓取、提取并分段翻译正文，不必离开当前网页；每个新域名首次读取时会请求授权
- 静态 HTML 没有正文时，会自动在非活动后台标签页渲染 JavaScript 页面，提取完成后立即关闭
- 标题、评论和文章正文翻译均显示已完成数量、总数和百分比进度
- 翻译批次默认使用 3 路并发请求，并在完成后按原文顺序组合结果
- 正文使用连续的杂志式阅读排版；评论使用带作者头像的冷灰色讨论卡片，和原帖清晰区分
- Ask HN、Show HN 等自带正文的原帖会和评论一起翻译，并保留可折叠英文原文
- 评论按需翻译，避免无意义消耗额度
- 支持 OpenAI、Anthropic、DeepSeek、Google Gemini，以及 OpenAI 兼容接口
- Token 只写入浏览器本机的 `chrome.storage.local`，不会发往除所选模型接口外的服务
- “关注”Tab 单独展示人工智能、编程、创业、安全、科学、硬件、设计、文化等兴趣内容；其他 Tab 始终保持 HN 官方内容与排序
- 本地持久化缓存；缓存键包含原文、服务商、模型及提示词版本
- 同一批次去重、跨并发请求合并、分批请求、过期清理和 LRU 容量限制

## 安装

1. 打开 Chrome 的 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 选择“加载已解压的扩展程序”，选择本项目目录。
4. 点击工具栏中的扩展图标，再进入“模型与话题设置”。
5. 只需选择模型、按照页面引导创建并粘贴 API Key，然后保存。
6. 再次点击扩展图标，浏览器右侧会打开常驻的中文 HN 阅读器。

使用自定义兼容接口时，Chrome 会在保存时请求该接口域名的访问权限。Token 不会同步到 Google 账号；卸载扩展会同时移除本地设置和缓存。

## 本地检查

```bash
npm test
npm run check
```

项目不依赖打包器或第三方运行库，整个目录可以直接作为未打包扩展加载。

## 缓存设计

缓存使用 SHA-256 键：`提示词版本 + 服务商 + 模型 + 去除首尾空白的原文`。只有模型完整返回与输入等长的 JSON 翻译数组后才写入缓存；失败请求不会污染缓存。默认保存 30 天、最多 5,000 条，超过容量时优先删除最久未访问的条目。修改模型或升级翻译提示词都会自然产生新的缓存空间，不会复用不兼容的旧翻译。
